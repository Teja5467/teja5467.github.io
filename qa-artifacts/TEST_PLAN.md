# OrangeHRM QA Test Plan

## Objective
Validate core OrangeHRM web application workflows from a software-testing perspective.

## Scope
Authentication, logout, dashboard/navigation, Admin user search, PIM employee search/reset, My Info validation, Leave navigation, and UI/validation checks.

## Testing Types
Functional, smoke, regression, positive, negative, validation and UI/usability testing.

## Environment
Chrome browser on Windows.

## Deliverables
Test cases, defect documentation, RTM, execution summary and Selenium Java automation.
